## Added

- Staff can edit existing AAC labels, emoji fallbacks, and Font Awesome icons.
- AAC editor shows a live visual preview for each item.
- Calm screen now uses IconSymbol.
- Communication repair now uses IconSymbol.
- Activity prep now uses IconSymbol.
- Activity reflection now uses IconSymbol.
- Switch scanning now uses IconSymbol.

## Accessibility rule preserved

The label remains the communication message.

The visual symbol is decorative and does not replace:

- visible text label
- read-aloud label
- screen-reader name
- support-event label
- documentation/export label
