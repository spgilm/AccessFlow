# AccessFlow v44 AAC Expansion + Social Communication Pack

## Added

- Core words board
- Quick phrases board
- Feelings + intensity scale
- Social scripts board
- Staff AAC expansion editor
- Expanded AAC communication preset

## Student support event types

```txt
aac-core-word
aac-quick-phrase
aac-feeling
aac-social-script
```

## Purpose

v44 expands student communication beyond schedule supports by adding targeted AAC boards.
This is not a full AAC replacement, but it adds practical communication access for:

- requesting
- rejecting
- repairing communication
- expressing feelings
- using social scripts
