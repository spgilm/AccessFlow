# AccessFlow v40 Feature Map

## Student-facing areas

| Area | Main purpose |
|---|---|
| Today | Schedule, current activity, supports, communication, regulation, life skills |
| Choose | Guided schedule builder and approved activity choices |
| Make | Student-created activities |
| Board | AAC / choice board and message strip |

## Staff-facing areas

| Tab | Main purpose |
|---|---|
| Dashboard | Snapshot overview and feature map |
| Setup | Guided setup workflow |
| Students | Profiles, presets, settings, supports |
| Choices | Activity bank, choice board, visual library, First/Then |
| Schedule | Schedule/date/template/activity editing |
| Notes | Documentation, goals, recommendations, handoffs, communication history |
| Save | Cloud sync, backup, security prototype, compliance/backend readiness |

## Recommended presets

- Simple visual schedule
- AAC / communication support
- Regulation and transition support
- High autonomy schedule builder
- Community access
- Vocational / job coach
- Residential / caregiver handoff
- Advanced full support
