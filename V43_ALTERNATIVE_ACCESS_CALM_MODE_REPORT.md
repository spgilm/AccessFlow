# AccessFlow v43 Alternative Access + Calm Mode Pack

## Added

- Calm screen
- Communication repair board
- Large-button help / support mode
- Switch scanning prototype
- Eye-gaze friendly layout preset
- Calm-first reduced-choice preset
- Staff alternative access guide

## Student-side purpose

v43 supports students who need fewer choices, larger buttons, stable layouts,
communication repair, or switch-scanning style access.

## Prototype note

Switch scanning is currently a front-end prototype. Real hardware switch integration,
dwell timing, and full row/column scanning should be handled in a later production phase.
