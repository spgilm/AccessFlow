# AccessFlow v41 Self-Advocacy Passport + Support Pattern Log

## Added

- Student-facing About Me / self-advocacy passport
- Staff About Me editor
- Copyable About Me export
- Staff quick observation/support pattern log
- Activity support pattern indicators
- "What worked last time?" style activity summaries

## Purpose

v41 connects communication, documentation, and individualized support planning.
It gives the student a plain-language profile and gives staff a faster way to
capture support observations.

## Data note

New profile fields:

```txt
aboutMeProfile
supportObservations
```

v41 also fixes new-profile defaults for:

```txt
lifeSkillsSettings
```
