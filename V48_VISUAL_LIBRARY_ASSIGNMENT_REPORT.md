# AccessFlow v48 Visual Library Assignment Pack

## Added

- Staff can assign saved Visual Library items to communication buttons.
- Assignment works in reusable StaffVisualChoiceEditor.
- Assignment works in AAC expansion editor.
- Supports saved emoji visuals.
- Supports saved Font Awesome icon visuals.
- Supports saved uploaded image/photo visuals.
- Student buttons still render through IconSymbol and keep visible labels.

## Why this matters

Different students may understand different visual systems. v48 lets staff use the profile's saved visual library across AAC, sensory, self-advocacy, community, and vocational buttons without replacing labels.

## Accessibility rule preserved

The assigned visual is a support only. The label remains the communication message, read-aloud text, screen-reader name, event-log value, and documentation/export value.
