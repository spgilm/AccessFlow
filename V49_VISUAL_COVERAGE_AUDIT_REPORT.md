# AccessFlow v49 Visual Coverage Audit + Suggested Icons Pack

## Added

- Visual coverage utility.
- Staff visual coverage audit panel.
- Summary of saved visuals, Font Awesome icons, emoji-only visuals, and text fallback.
- Weak visual support indicators.
- Suggested icon generation from item labels.
- One-click application of suggested icons across AAC, communication, self-advocacy, and life-skills settings.

## Accessibility rule preserved

Icons are visual supports only. The item label remains:

- visible student text
- read-aloud text
- screen-reader name
- event-log value
- documentation/export value
