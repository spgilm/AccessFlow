# AccessFlow v42 Activity Readiness + Reflection Pack

## Added

- Student activity prep support
- Student activity reflection
- Student try-again-later request
- Staff activity readiness review
- Staff try-again-later queue

## Purpose

v42 helps students prepare before activities, reflect after or during them,
and request to try difficult tasks later without deleting the schedule item.

## Data flow

Student tools record support events:

```txt
activity-prep
activity-reflection
try-again-later
```

Staff review panels summarize those support events alongside staff observations.
