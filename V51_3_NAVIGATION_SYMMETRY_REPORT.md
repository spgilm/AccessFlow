# AccessFlow v51.3 Navigation Symmetry Pack

## Purpose

v51.3 gives Student Mode and Staff Mode matching 8-tab navigation with a 2x4 grid feel.

## Student tabs

```txt
Profile | Schedule | Choose | Make
Board   | Help     | Relax  | Games
```

## Staff tabs

```txt
Dashboard | Setup | Students | Choices
Schedule  | Notes | Reports  | Save
```

## Student changes

- Added Help as the 8th student tab.
- Moved urgent support, break, yes/no, help builder, decision, stuck, and schedule-change tools into Help.
- Kept Relax focused on sensory, regulation, waiting, calm screen, communication repair, and switch scanning.
- Kept Board focused on communication boards, AAC, and community/work cards.

## Staff changes

- Added Reports as the 8th staff tab.
- Kept Notes focused on direct documentation entry and observations.
- Moved weekly progress, handoff, communication history, support patterns, readiness review, try-again-later queue, recommendations, caregiver handoff, and About Me export into Reports.

## Safety

This remains a prototype only. It is not HIPAA certified or FERPA certified.
