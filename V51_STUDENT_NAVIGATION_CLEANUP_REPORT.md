# AccessFlow v51 Student Navigation Cleanup Pack

## Purpose

v51 reduces Student Mode clutter by splitting the old overloaded Today screen into clearer sections.

## New Student Mode sections

```txt
Profile
Schedule
Choose
Make
Board
Relax
Games
```

## What moved

- Profile: About Me, check-in, rewards, progress.
- Schedule: date picker, activity readiness tools, First/Then, and the schedule list.
- Choose: guided schedule builder and activity bank.
- Make: student-created custom activities.
- Board: choice board, AAC tools, self-advocacy, community/work cards.
- Relax: help, break, transitions, body/sensory/waiting supports, calm screen, repair, switch scanning.
- Games: placeholder for future calming games.

## Scope

No backend changes. This is a Student Mode navigation and layout cleanup.
