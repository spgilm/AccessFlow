## Purpose

v52 turns the Student Mode Games tab into a real prototype game area.

```txt
Snake

Memory Match
Float Bird
```

## Accessibility-oriented design choices

- Large touch buttons.
- Visible text labels.
- Simple game instructions.
- No violent Hangman language or imagery.
- Touch-first controls.
- Low-stimulation visual style.
- No backend changes.
- No student/client data required.
