## Added

- Font Awesome Free React dependencies
- Curated icon registry
- Reusable IconSymbol component
- Staff Font Awesome icon library/picker
- Font Awesome icon visual type for Visual Library
- Icon support in AAC expansion boards
- Staff AAC editor icon selector
- Font Awesome license note

## Accessibility rule

Icons do not replace labels.

The label remains:

- visible under the visual
- the communication message
- the read-aloud text
- the screen-reader name
- the support-event log value
- the export/documentation value

## Visual fallback order

```txt
uploaded image/photo
Font Awesome icon
emoji
text-first-letter fallback
```
