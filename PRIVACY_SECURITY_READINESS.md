# Privacy and Security Readiness

## Current privacy posture

AccessFlow includes warnings and prototype data-health tools. It is not ready for real student/client data.

## Data minimization recommendation

Start with non-identifying fields:

```txt
Profile nickname
Non-identifying routines
Generic visual supports
Mock documentation notes
```

Avoid:

```txt
Full legal names
Birth dates
Addresses
Medical diagnoses
IEP/ISP official text
Photos of real students/clients
Family contact information
Medication information
Incident details that identify a person
```

## Production privacy features to add

```txt
Organization workspace
User membership roles
Access logs
Export logs
Record retention controls
Record deletion controls
Consent/disclosure metadata
Parent/guardian/eligible-student access workflow
Amendment/correction request workflow
Admin privacy dashboard
```
