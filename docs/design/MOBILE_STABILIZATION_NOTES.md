# AccessFlow v40 Mobile Stabilization Notes

## Current mobile strategy

- Student Mode uses grouped/collapsible panels.
- New v31-v39 tools are not placed directly in the primary schedule.
- Small screens get `student-mobile-quick-nav`.
- Large touch mode can be applied by feature preset.
- Presets reduce the need to expose every feature for every student.

## Main mobile risk

The app is feature-rich. The biggest mobile risk is cognitive load, not pure responsiveness.

## v40 mitigation

v40 adds broad feature presets and a staff feature map so staff can configure the interface for the actual student/client instead of leaving every tool visible.
