# AccessFlow v33 Mobile Polish Notes

## Added in v33

Student Mode now includes a small-screen quick navigation bar:

```txt
student-mobile-quick-nav
```

It appears on narrow screens and mirrors the available Student Mode tabs.

## Design intent

- Keep phone navigation reachable.
- Avoid adding more visual load to desktop/tablet layouts.
- Respect Student Mode presets and display settings.
- Preserve the existing grouped/minimal panel system.
