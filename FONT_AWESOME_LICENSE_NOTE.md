# Font Awesome Free License Note

AccessFlow v45 uses Font Awesome Free through the official npm packages:

```txt
@fortawesome/fontawesome-svg-core
@fortawesome/free-solid-svg-icons
@fortawesome/free-regular-svg-icons
@fortawesome/react-fontawesome
```

Font Awesome Free is used only as a visual symbol source. The visible text label remains the communication message, read-aloud text, screen-reader name, event-log value, and export/documentation value.

Review Font Awesome's current Free license terms before production use. At the time this prototype note was added, Font Awesome Free documented separate license terms for icons, fonts, and code. Keep attribution/license documentation with any production release.
